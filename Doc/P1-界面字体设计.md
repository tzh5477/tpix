# P1 界面字体 · 设计（2026-10-10）

> 对应《竞品对比刷新分析-含Snipaste.md》P1 表里的「**主题色 / 界面字体**」（借鉴 Snipaste）。
> 主题色已落地（`8f01cf6`），本文只讲字体。

## 0. 结论摘要

| 项 | 决定 |
| --- | --- |
| 能力 | 设置页选一个**界面字体族**，全界面文字（不含图标字体）跟着换 |
| 配置键 | `ui.font`（字符串，空串 = 内置默认「Microsoft YaHei」） |
| 上游改动 | **需要**：`Ling` 加一个全局默认字体入口（约 20 行）。这是本项唯一的上游侵入点 |
| 枚举字体 | **不需要**上游：`D2D::dwriteFactory` 已是 public，tpix 自己枚举系统字体族 |
| 生效时机 | 选完**立即**对已开窗口生效（`Text::makeLayout` 每次都重取格式，触发一次重排即可） |

## 1. 现状（Ling 侧，已核实）

```cpp
// D2D.cpp:63 initFont()  —— 设备每次重建都会跑一遍
dwriteFactory->CreateTextFormat(L"Microsoft YaHei", nullptr, ... 12.f, L"zh-CN", baseTextFormat...);

// D2D.cpp:157 getTextFormat(family)
if (fontFamily.empty() || customFormats.empty()) return baseTextFormat.Get();
// 自定义字体集合里没有的族名 → 也是 baseTextFormat
```

要点：

1. **族名写死**在 `initFont()` 里；`baseTextFormat` 就是"没显式指定族名的所有文字"用的那一份。
2. **`getTextFormat` 的分流规则**：自定义字体（图标字体）走 `customFormats`，其余全部回落到
   `baseTextFormat` —— 所以改这一份 = 改整个界面，且**不会**影响图标字体。
3. **设备会被销毁重建**（最后一个窗口关掉时 `D2D::dispose()`），`initFont()` 随之重跑 ⇒
   选中的字体必须存在**静态成员**里，重建时接着用（同 `static std::vector<std::wstring> fontNames`
   的既有范式）。
4. `Text::makeLayout()` 每次建 layout 都调 `getTextFormat(fontFamily)` ⇒ 换掉 base 之后，
   已开窗口**重排一次**就能换过来，不必重启。

## 2. 上游（Ling）改动

`include/D2D.h` + `src/D2D.cpp`，两处：

```cpp
// D2D.h —— public
// 换掉默认字体族（界面里没显式指定族名的文字都用它）。空串 = 回到内置默认。
// 只登记 + 立刻重建 baseTextFormat；设备重建时会按登记值重建，所以换过就一直有效
static void setDefaultFontFamily(const std::wstring& family);
// 取当前生效的族名（设置页要显示它，也让 tpix 不必自己记一份）
static std::wstring getDefaultFontFamily();

// private
static std::wstring defaultFamily;   // 空 = 内置默认
```

```cpp
// D2D.cpp
std::wstring D2D::defaultFamily;

void D2D::initFont()
{
    ...
    const std::wstring family = defaultFamily.empty() ? L"Microsoft YaHei" : defaultFamily;
    hr = dwriteFactory->CreateTextFormat(family.data(), nullptr, ... , 12.f, L"zh-CN",
                                        baseTextFormat.ReleaseAndGetAddressOf());
    // 创建失败（用户手改配置写了个不存在的族名 / 字体被卸载）：悄悄退回内置默认，
    // 绝不能让界面变成"全部文字都不显示"
    if (FAILED(hr)) {
        dwriteFactory->CreateTextFormat(L"Microsoft YaHei", nullptr, ..., 12.f, L"zh-CN",
                                        baseTextFormat.ReleaseAndGetAddressOf());
    }
}

void D2D::setDefaultFontFamily(const std::wstring& family)
{
    if (defaultFamily == family) return;
    defaultFamily = family;
    if (d2d) d2d->initFont();     // 设备在就立刻重建；不在就等下次建
}
```

⚠️ 两个必须守住的点：

- **不能因为换字体就把 D3D 拉起来**：设备没建（启动到托盘）时 `setDefaultFontFamily` 只登记，
  同 `addFonts` 的注释口径一致。
- **失败要能自愈**：族名不存在时 `CreateTextFormat` 返回失败且 `baseTextFormat` 为空 ——
  那样整个界面就没有文字了。必须像上面那样回退。

### 3.1 生效与重排

选完字体后：

1. `Setting::setUiFont(f)`（落盘）
2. `Ling::D2D::setDefaultFontFamily(f)`（重建 base 格式）
3. **让已开窗口重排**：对每个活着的顶层窗口调一次 `refresh()`/`relayout`。
   最省事的做法是在 `WinSettingCommon` 里对自己所在的窗口调一次即可 —— 设置窗本身就换了，
   用户立刻看得到；其它窗口（贴图、悬浮球）多为无文字或下次重建时自然生效。
   ⚠️ 不要为此去遍历所有窗口强行重排：`refresh()` 会连带重画，贴图窗口重画会闪一下。

### 3.2 图标字体不受影响（已验证的分流）

`getTextFormat` 里：族名属于 `customFormats`（`addFonts` 登记的自定义字体，图标字体在内）
就返回绑了自定义集合的那份；**其余一律回落到 base**。所以换 base 不会让图标变成方块。

## 4. 风险

| 风险 | 对策 |
| --- | --- |
| 用户配置文件里写了不存在的族名 | `initFont` 创建失败时回退内置默认（§2 已写死） |
| 有些族名是"字体文件里的本地化名"，下拉里选中的名字与 `SetFontFamilyName` 需要的一致 | 枚举时用 `IDWriteFontFamily::GetFamilyNames()` + `GetLocaleName` 取与系统语言匹配的那一个，并**原样存进配置** |
| 等宽/图标混排错位 | 换 base 只影响非图标文字；`monoFont` 那套行内样式路径不变（`Text.cpp:212`） |
| 别把字体大小也顺手做了 | 本轮只换族名。`baseTextFormat` 的 12.f 字号不动 —— 动字号要连带 `Label`/`Button` 里那些硬编码的 `setFontSize` 一起审，是另一件事 |

## 5. 验收

1. 设置页出现「界面字体」下拉，列出系统字体（中文名优先）。
2. 选中「宋体」→ 设置窗自己的文字**当场**变宋体（含"界面字体"这一行本身）。
3. 重启 tpix → 仍是宋体（落盘生效），且 `D2D::initFont` 重建后没退回雅黑。
4. 图标（工具条上的画笔/复制等）**不变方块**。
5. 手改配置文件 `ui.font = "NoSuchFont"` → 重启后界面文字正常（回落默认），不空白。
